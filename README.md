# Sistema de Gerenciamento de Pequeno Mercado

## Sobre o projeto
Projeto de estudo desenvolvido com MySQL, com o objetivo de criar um banco de dados para gerenciamento de um pequeno mercado.

A proposta é aplicar conhecimentos de modelagem de banco de dados, relacionamentos entre tabelas e consultas SQL em uma situação prática.

## Objetivos
- Cadastro de produtos.
- Identificação por código de barras.
- Gerenciamento de categorias e fornecedores.
- Controle de estoque.
- Registro de vendas.
- Consultas e relatórios.

## Tecnologias utilizadas
  - MySQL
  - SQL
  - MySQL Workbench

 ## Estrutura de banco de dados
   - Categorias
   - Fornecedores
   - Produtos
   - Vendas
   - Itens_venda

  ## Conhecimentos aplicados
   - Criação de tabelas.
   - Chaves primárias e estrangeiras.
   - Relacionamentos 1:N.
   - Comandos INSERT, SELECT, UPDATE e DELETE.
   - Consultas com JOIN.

 ## Status do projeto
